# NYC 3D Building Explorer

Interactive 3D building visualisation application built using Streamlit, GeoPandas and PyDeck.

## Features

- Visualise buildings in 3D
- Explore building heights
- View tallest buildings
- Interactive map navigation

## Technologies

- Python
- Streamlit
- GeoPandas
- PyDeck

## Run

```bash
streamlit run Buliding-Height.py
